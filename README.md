# Полиця настілок

Трекер настільних ігор у стилі MyAnimeList: оцінка 1–10, окремі оцінки на
2, 3, 4 і 5+ гравців, партії, теги, нотатка вручну, вибірка за складом столу
й порівняння до чотирьох ігор поруч.

## Дві копії, дві бази

| Копія | Де дані | Коли зручна |
|---|---|---|
| **Онлайн** — [опублікована сторінка](https://claude.ai/code/artifact/cbc24574-963f-41eb-81c4-592f14bc1c9e) | база артефакта на claude.ai | заповнювати з телефона одразу після партії; видно з будь-якого пристрою |
| **Офлайн** — `Полиця настілок.html` | пам'ять браузера (`localStorage`) на цьому комп'ютері | без інтернету; свій окремий список |

Бази **не синхронізуються**. Перенести все з однієї в іншу: `···` →
«Експортувати JSON», потім у другій копії `···` → «Імпортувати JSON…»
(імпорт додає нові ігри й оновлює наявні за назвою чи id, нічого не стирає).

## Файли

* `сторінка.html` — **джерело**, воно ж іде на публікацію. Без `doctype`
  і `<head>`: їх додає claude.ai. Правити треба саме його.
* `Полиця настілок.html` — офлайнова копія, **збирається** з джерела.
* `збірка.py` — обгортає джерело в самодостатній файл (`<meta charset>`
  обов'язковий, інакше кирилиця перетворюється на кракозябри).

Після будь-якої правки джерела:

```
python "збірка.py"
```

і перепублікувати `сторінка.html` тим самим шляхом — посилання лишиться те саме.

## Історія і резервні копії

Тека — окремий локальний git-репозиторій **без віддаленого**. В історію йдуть
джерело, збирач і ця нотатка; зібраний файл — ні, він відтворюється командою.
Перед публікацією корисно глянути `git diff`: у файлі на 900 рядків зламана
правка не падає з помилкою, а тихо вбиває сторінку.

Git **не бачить твоїх оцінок** — вони в базі артефакта й у `localStorage`.
Резервна копія даних робиться інакше: `···` → «Експортувати JSON», файл у теку
`резервні/` (вона в `.gitignore`). Опублікована сторінка додатково зберігає
власні версії на claude.ai.
